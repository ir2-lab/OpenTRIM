# Validation

Validation is done mainly by comparing OpenTRIM output to other codes and theoretical results, not experimental data.

Comparison to SRIM is most important, due to the wide acceptance of this code and due to the fact that SRIM results have been tested against a large experimental dataset.

Some comparisons have been done also to IRADINA, MARLOWE and MD simulations.

See the corresponding sub-folders:
1. [Damage generation](./damage_generation/README.md)
2. [Damage profiles](./damage_profiles/README.md)
3. [Multiple scattering](./multiple_scattering/README.md)
4. [Defect recombination](./defect_recombination/README.md)
